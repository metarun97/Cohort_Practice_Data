-> Declarative = React is a declarative library we describe what you want to do not specific how we get it done.
-> Component Based = React is a Component based library where we brak our monolith desigen pattern into small small components to reuse it again and again.


Q. Why React is a library why it isn't a framework...?
Ans. It is a library because it is used only for desigen UI and it hasn't inbuild routing,testing etc and when we want these unbuild features we can install and use it what we want so it is a library thats it.


Q. State VS Props...?
Ans. State = state are the local variables which is used in only inside the function.
     Props = props are the arguments that can be passed as an argument for a function to excess it by another function.

Q. What is react Hooks...?
Ans. Hooks are simple functions that we can use to seperate out the reusable part from the functional components.It can be statefull and can manage side effects.


Q. What is useState hook...?
Ans. useState is used to add data in your component and update it inside the component.

Q. What is useEffect hook...?
Ans. useEffect is used after rendering a component for doing extra works in it.

Note -> 1. Agar dependency array nahi denge → useEffect har render pe chalega.
Note -> 2. Agar dependency array empty [] denge → useEffect sirf initial render (mount) pe ek baar chalega.
Note -> 2. Agar dependency array me state/props denge → useEffect sirf tab chalega jab wo state/props change honge.

Q. What are the side effects of useEffect hook...?
Ans. 1.DOM Manipulation
     2. Async API calls
     3. Writing to a storage (localStorage)
     4. Input/Output operation
     5. Subscription
     6. Even,a console.log()
